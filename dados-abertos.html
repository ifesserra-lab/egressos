API estática

Para consumir de um site, notebook ou LLM em vez de baixar tudo: recortes menores, campos estáveis e um índice que lista todos os endpoints. Mesma licença, mesma anonimização. 

curl https://ifesserra-lab.github.io/egressos/api/index.json
coorte.json 6,7 KB coorte/serie-por-experiencia.json 1,7 KB coorte/serie-por-ano.json 2,7 KB coorte/trajetoria-destaque.json 2,7 KB salario-minimo.json 4,4 KB indices.json 17,5 KB mercado/stackoverflow.json 5,7 KB mercado/codigofonte.json 4,1 KB empresas/index.json 35,3 KB empresas/<slug>.json por item analise.json 13,7 KB egressos/perfis.json 78,3 KB egressos/renda-por-senioridade.json 6,1 KB fomento-fapes.json 1 KB mapa/base.json 34 KB mapa/detalhe.json 289,4 KB

Sem chave, sem limite de uso e sem servidor: são arquivos estáticos no GitHub Pages, regerados a cada atualização do relatório.

Como reproduzir

# exige os JSON de mercado (Stack Overflow, IPCA) e a base de perfis, que não é pública
make build       # gera todos os JSON e valida (QA + varredura de PII)
make site-build  # constrói o site a partir deles
make publish     # copia a versão aprovada para os sites

O portão de publicação reprova se qualquer nome de pessoa vazar para o HTML ou o JSON público — e reprovando, nada é copiado. Metodologia completa →
